# Guía de Contribución y Colaboración

Este repositorio está destinado exclusivamente al equipo de colaboradores del proyecto **Bases de Datos** (`proyectobd-17392-gcc2026`).

## Reglas de Trabajo

1. **Acceso**: Solo los colaboradores autorizados del repositorio pueden crear ramas internas, revisar Pull Requests y fusionar cambios en `main`.
2. **Rama principal (`main`)**: No realizar commits directos sobre `main`. Todo cambio debe pasar por Pull Request y revisión de un colaborador (`CODEOWNERS`).
3. **Flujo recomendado**:
   - Crear una rama desde `main` (por ejemplo: `feature/modulo-usuarios` o `fix/consulta-sql`).
   - Realizar los cambios en `backend/` (Spring Boot) o `frontend/` (Angular).
   - Abrir un Pull Request hacia `main` usando la plantilla del repositorio.
   - Esperar la aprobación de un colaborador antes de hacer merge.
